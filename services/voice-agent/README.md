# Voice Agent — @index0/voice-agent

Sub-100ms Multimodal WebRTC Voice and Pipecat Pipeline Microservice for INDEX0 AGI.

## Features
- **LiveKit Agents SDK Integration**: Real-time WebRTC room token generation, session tracking, and audio frame forwarding.
- **Pipecat Pipeline**: Modular frame-based audio pipeline: Speech-to-Text (STT) → LLM (LiteLLM) → Text-to-Speech (TTS).
- **Sub-100ms Latency**: Designed for conversational voice interactions with semantic endpointing and turn-taking.
- **FastAPI HTTP & WebSocket API**: Session token generation and lifecycle events.
