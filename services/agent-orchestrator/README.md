# Agent Orchestrator — @index0/agent-orchestrator

Multi-Agent Coordination and 4-Tier Review Loop Microservice for INDEX0 AGI.

## Features
- **4-Tier Review Loop**: Architect → Developer → Critic → QA with stateful review cycles.
- **Git-Native Agent Protocol (GNAP)**: Git commit-based agent communications and coordination.
- **TextGrad Feedback Engine**: Textual backpropagation optimizing code implementations based on multi-stage critique.
- **FastAPI HTTP API**: Async cycle start, step progression, and status tracking.
