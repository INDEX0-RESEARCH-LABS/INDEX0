Pre-seed · November 2026 · INDEX0 Research Labs

Verification before merge. A self-hosted, four-tier review loop (Architect, Developer, Critic, QA) where the QA tier executes the candidate code against the repository's own test suite in a network-isolated container. The verdict is an exit code, not a model's opinion of the diff.

Problem

AI coding tools produce plausible code that passes the wrong tests. Every existing review layer (Copilot, Cursor, Qodo, OpenHands) reports findings or scores; none hands a regulated customer a replayable artifact proving the fix ran. AI-assisted teams ship 3–4× the code with 10× the security findings, and auditors now ask for evidence.

Product

  • Developer output is whole files (models are bad at hunk arithmetic); the unified diff is derived by us.
  • Critic review is advisory-only: request_changes with no critical/error finding is auto-upgraded to approve.
  • QA copies the repo into a container with --network none, writes the candidate, runs npm test, reports exit code and counts the runner printed.
  • Candidate edits to test files are dropped, so the assertions that decide the verdict are always the repository's own.
  • Every cycle is hash-chained and attributable (GNAP).
