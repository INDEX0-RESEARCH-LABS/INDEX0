INDEX0 AI

Pre-seed · November 2026 · INDEX0 AI Inc.

Own your AI engineer. A self-hosted, multi-agent AI software engineering platform. You ask for code in your terminal, editor or browser; four agents plan, patch and critique it; the last one executes it against the repository's own test suite in a network-isolated container. Nothing merges until it runs — on your infrastructure, with your model key.

Surfaces

  • Terminal — the index0 CLI and TUI: run, plan, review, worktrees. 37 tests.
  • Editor — VS Code extension, 7 commands including GhostText and GNAP diff review. 4 tests.
  • Browser — React workbench and the portal at ai.index0.in. 94 tests.

Problem

90% of developers use AI at work (DORA 2025) and 45% of the code it writes ships an OWASP flaw (Veracode 2025). The assistants that write it live in their own cloud and stop at the diff; the reviewer still reads 400 lines an hour, and the regulated buyer is told to send source out and rent a seat forever.

Product

  • Developer output is whole files (models are bad at hunk arithmetic); the unified diff is derived by us.
  • QA copies the repo into a container with --network none, writes the candidate, runs npm test, reports the exit code and the counts the runner printed.
  • Candidate edits to test files are dropped, so the assertions that decide the verdict are always the repository's own. Every cycle is hash-chained (GNAP).
