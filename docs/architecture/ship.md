## 2. Component Specifications

### 2.1 Temporal Workflows (`services/workflows` & `infra/temporal`)
Complex, long-running agent tasks must survive infrastructure restarts, network blips, and worker evictions. Temporal provides durable virtual execution:

#### `AgentExecutionWorkflow`
1. **Create Workspace**: Initialize safe workspace and load Git context.
2. **Start Sandbox**: Request microVM from Sandbox Manager.
3. **Start Agent**: Initialize OpenHands loop with prompt and context.
4. **Execute Tools**: Route tool requests to MCP Host and execute in sandbox.
5. **Collect Results**: Capture git diffs, outputs, and status.
6. **Persist Events**: Write state transitions to PostgreSQL.
7. **Finalize Execution**: Teardown sandbox and commit run status.
8. **Record Usage**: Emit usage metrics to Telemetry pipeline.

All activities define exponential backoff retries, explicit timeouts, and circuit breakers.

### 2.2 Coolify Deployment Orchestration (`services/deployment`)
INDEX0 AI leverages Coolify as a sovereign container orchestration engine:
- Triggers container builds and deployments via Coolify's REST API.
- Spawns preview environments for PRs generated by autonomous agents.
- Enforces container health checks before routing production traffic.

### 2.3 ClickHouse Analytics (`infra/clickhouse` & `services/telemetry`)
ClickHouse stores append-only, high-cardinality telemetry:
- **`audit_events`**: Security, authentication, and RBAC actions.
- **`agent_execution_metrics`**: Token consumption, step counts, duration, LLM latencies.
- **`api_requests`**: Gateway request logs, status codes, and latency distributions.

ClickHouse is accessed only via internal services over the private network.
